# Hoofdmenu & instellingen

Via het hoofdmenu krijg je snel toegang tot de verschillende onderdelen van de applicatie, zoals delen,
ondersteuning en het leegmaken van de cache. Je opent het hoofdmenu door rechtsboven op het **MapGallery-logo** te
klikken.

<!-- SCREENSHOT: menu/menu.png — Hoofdmenu van een ingelogde gebruiker -->

| Onderdeel | Functie |
|-----------|---------|
| **Ingelogd als** | Toont met welk account je bent ingelogd. |
| **Naar beheeromgeving** | De beheeromgeving openen. Alleen beschikbaar voor beheerders; zie [Beheerder](../../admin/index.md). |
| **Wat is er nieuw?** | Een overzicht van de belangrijkste wijzigingen in de nieuwste versie. Na het bekijken verdwijnt deze optie uit het menu. Alle wijzigingen staan in de [release notes](../../changelog/index.md). |
| **Delen → Link kopiëren** | Een link naar het huidige kaartbeeld kopiëren. Zie [Link kopiëren](../export/index.md#link-kopieren). |
| **Delen → Kaart als afbeelding** | Het kaartbeeld opslaan als PNG-afbeelding. Zie [Kaart als afbeelding](../export/index.md#kaart-als-afbeelding). |
| **Ondersteuning → Help** | Deze documentatie openen. |
| **Ondersteuning → Over deze applicatie** | Informatie over de versie van MapGallery, contactgegevens en licenties. |
| **Ondersteuning → Cache leegmaken** | De lokaal opgeslagen kaartgegevens wissen. Zie [Cache leegmaken](../troubleshooting/index.md#cache-leegmaken). |
| **Aanmelden** / **Afmelden** | Inloggen of uitloggen. Zie [Inloggen](../index.md#inloggen). |

## Weergave

- **Donkere modus**: MapGallery volgt de instelling van je besturingssysteem. Gebruikt je computer, tablet of telefoon
  een donker thema, dan wordt MapGallery ook donker weergegeven.
- **Breedte van panelen**: sleep de rand van een paneel, zoals Locatie-informatie, om het paneel breder of smaller te
  maken.
